# 拾词：五套完整设计方案

这是针对 0.3.0 的设计评审，不是已经修改好的应用。每套使用内置 image_gen 独立生成六屏总览：学习首页、查词详情、主动回忆、揭晓评分、复习安排、我的词书。五套共享同一份功能和示例数据，比较的是布局、视觉与交互取向。生成图中文字或数字如有偏差，实际实现以此说明及现有业务规则为准。

## 选型对照

| 方案 | 主要气质 | 布局特点 | 更适合 |
|---|---|---|---|
| A 墨白书页 | 安静、克制、书刊感 | 英文衬线字、开放排版、细线分区、少量朱红 | 喜欢阅读纸书、希望长期使用不疲劳 |
| B 原生晴空 | 明快、亲和、原生感 | 蓝紫主色、圆角模块、醒目任务入口、圆润控件 | 喜欢现代 Android 界面和清晰操作反馈 |
| C 山间留白 | 自然、舒缓、有呼吸感 | 淡山景、玉绿色、开放学习区、轻量日程 | 想让背词过程更放松，有一点环境氛围 |
| D 夜航专注 | 沉静、精密、深色优先 | 石墨层级、暖白字、琥珀操作色、大面积净空 | 主要在夜间或低光环境学习 |
| E 瑞士索引 | 清晰、理性、利落 | 强网格、无衬线大字、蓝色分区、索引式列表 | 重视信息密度、快速扫描和明确层级 |

## 六个主要页面的统一逻辑

1. **学习首页**：当前词书和今天日期在顶部；待学、到期复习是主要信息；主按钮优先继续未完成的组，其次开始学习。复习有独立入口。七天日历放在任务之后，统计放在日历之后，避免挤占首屏操作。
2. **查词详情**：单词、音标和发音在顶区；学习释义、全部释义是独立分段。编辑排序明确标注非频率统计，来源参考按需展开。底部固定“已加入 N 次”和“再次加入 +1”，加入后给予轻触觉和简短反馈，不强制离开查词页。
3. **主动回忆**：隐藏中文答案，突出单词与音标；进度、退出和撤销为辅助操作。下方固定“显示答案”，聚焦学习时不显示底部主导航。
4. **揭晓评分**：答案向下展开，正文可以滚动，底部评分区保持位置。忘记、困难、记得、轻松始终显示文字与整天间隔，颜色只作为辅助。评分后进入下一词，允许撤销上一条。
5. **复习安排**：只将已到期词放入今日队列，同等到期条件下优先加入次数多的词。先显示词和加入次数，不提前泄露中文答案；未来日期只是预测。复习答题复用主动回忆/揭晓布局，顶端标识为“复习”。
6. **我的词书**：词书切换、新建、搜索、单词列表，加入次数保持独立列。待学次数与到期状态分别标注，不能用“3 次”同时表达两个含义。删除由明确菜单进入，并说明删除对象。

生成图示例为 address。四档的 1/1/2/8 天只是默认新词示例，实装由调度器动态给出，绝不写死在界面。首页和列表数值是演示数据。

## A · 墨白书页

- **颜色**：纸白 `#F7F3EA`、墨黑 `#232524`、灰字 `#74746C`、朱红 `#AF493A`。朱红仅用于当前操作和少量选中状态；错误提示配合图标和文字。
- **排版**：英文单词使用系统衬线体 44–52 sp；中文系统无衬线体，正文 17 sp / 行高 26 sp。首页大数字与留白建立层次；词典义项用细线和编号分隔。
- **形状**：6–10 dp 小圆角，24 dp 页面边距，卡片尽量由排版关系替代，避免一屏连续套卡。
- **各页特点**：首页像每日阅读页；查词像词典条目；回忆页左对齐单词；复习为目录；词书为索引。操作按钮保留清晰实色底。
- **动效**：轻微上移与淡入，160–220 ms；揭晓通过透明度和短距离展开实现，不做拟真翻书旋转。按下反馈简洁。
- **暗色适配**：暖炭黑 `#1D1B18`、米白 `#F0EADF`、柔和陶红 `#D89885`；沿用相同排版，降低分隔线对比。

## B · 原生晴空

- **颜色**：冷白 `#F7F8FE`、晴空蓝 `#4E62D8`、淡紫 `#E5E7FF`、浅柠檬 `#F4E8A4`、深蓝文字 `#17243B`。
- **排版**：系统无衬线体，英语 46–52 sp，中文正文 17 sp；数字和按钮的字重比说明文字更突出。
- **形状**：24–32 dp 圆角主要模块，16–20 dp 输入/评分控件。任务区使用一大两小的分组关系，辅助统计更平。
- **各页特点**：首页任务入口醒目；查词分段圆润；单词居中；四档评分形成平衡的 2×2 操作区；词书采用较宽松的列表分组。
- **动效**：轻阻尼弹簧体现按压/返回反馈，页面切换 200–260 ms；选中指示器连续移动，减少整页大范围缩放。
- **暗色适配**：深蓝灰 `#151923`、抬升表面 `#202737`、浅蓝 `#BAC5FF`，黄色仅做小范围提示，文字保持对比。

## C · 山间留白

- **颜色**：粉笔白 `#F5F6F1`、深玉绿 `#2B5B50`、雾绿 `#C8D9CA`、淡桃 `#E9C6B1`。
- **排版**：系统无衬线体，中等字重单词 46–50 sp；正文左对齐，核心回忆词居中。
- **形状**：16–20 dp 圆角，轻量层次，24–28 dp 页边距；背景使用原创简洁山形轮廓，保持文字区域纯净。
- **各页特点**：首页有较小面积的环境图形与清晰任务条；回忆页面开放；查词是干净白底；复习是纵向轻量日程；词书为图书目录式列表。
- **动效**：180–260 ms 的轻缓淡入/短距离位移；山景保持静止，不添加循环漂浮、粒子或持续视差。
- **暗色适配**：深青灰 `#151E1B`、苔绿表面 `#22332A`、浅玉绿 `#BAD5C5`；山形降低饱和度和对比，避免影响阅读。

## D · 夜航专注

- **颜色**：近黑 `#101318`、石墨 `#1D232B`、暖白 `#F1F0E9`、琥珀 `#DDBA79`、雾青 `#8DB7C4`。
- **排版**：清晰系统无衬线体，英文 48–54 sp，主文 17–18 sp，避免细字重和小号灰字。
- **形状**：12–16 dp 圆角，边界依靠表面明度和细线；不使用霓虹发光、玻璃模糊和大阴影。
- **各页特点**：首页一个明确的当日进度图搭配任务行；学习页净空最大；释义分区克制；评分区抬升一层；词书与复习为低干扰的日程列表。
- **动效**：160–220 ms 快速淡入/小幅移动，反馈清楚；页面转场避免整屏亮度闪烁。
- **浅色适配**：灰白 `#F5F5F0`、墨色 `#24282E`、深琥珀 `#795825`。浅色按钮使用深色背景配浅字，不能直接把深色琥珀搬到白底当小字。

## E · 瑞士索引

- **颜色**：纯白 `#FFFFFF`、近黑 `#171B22`、群青 `#244CDF`、少量索引黄 `#F3D84B`。
- **排版**：系统粗体无衬线英语 48–54 sp；数字、分区和细线形成明确网格；中文正文 17 sp，阅读长释义时使用正常字重。
- **形状**：4–8 dp 圆角，强对齐，页面边距 24 dp；输入、列表和按钮用线/底色区分，不做圆泡卡片。
- **各页特点**：首页双列大数字；学习左对齐大词与显式序号；揭晓是编号义项；复习与词书像精确的索引表；计数固定在右列。
- **动效**：短距离滑移 150–210 ms，分页方向一致；选中下划线平移，强调位置关系。
- **暗色适配**：冷黑 `#12161C`、暖白 `#F1F3F6`、明蓝 `#A8BAFF`，分隔线降对比，黄色仅做小标记。

## 其他完整状态与原生交互

- **我的/设置**：同一视觉系统中的分组列表，包含外观、每组学习量、目标保持率、数据来源、许可和清除个人数据。日常学习页不堆放技术说明。
- **空词书/首次使用**：一句说明加“去查词”，不用复杂新手教程。
- **今日无到期**：显示“今天的复习已完成”和下一到期日期；可以去学习新词，不把未来复习提前算作今日任务。
- **遗忘等待**：显示具体可继续日期，保留未完成任务；提供回首页/学习其他词入口，不用分钟倒计时。
- **一组结束**：简短展示本组完成量与仍需巩固量，提供继续下一组、回首页、撤销上一条；不把“忘记”统计成已掌握。
- **查询无结果/加载/错误**：提示具体状态，保留输入及个人数据，给出重试或返回入口；不出现无限旋转或空白页。
- **词书切换**：原生底部弹层；所有可操作元素有明确文字或无障碍说明。学习中返回保存进度，重进先恢复原组。
- **键盘和手势**：查词页适配输入法，结果页点击后收键盘；焦点学习支持系统预测性返回；不把评分绑定成唯一的滑动手势。
- **大字号和横屏**：文字最多放大后重排；四档评分可转为两列；单词过长自动降一级字号或换行；内容区滚动，底部操作区保持可见。
- **可访问性**：触控区域至少约 48 dp；正文优先达到 4.5:1 对比度；错误和评分不只靠颜色区分；动画遵循系统移除动画设置。
- **高刷新率**：采用 Android/Compose 帧同步，使用短时属性动画；静止页面不持续绘制。具体动画平滑度在选定方案实现后进行设备验收。

## 后续落地顺序

用户选择一个编号后，先固定配色、字号、形状、控件和导航规范；再更新六个主要页面及设置、空/错/等待/完成状态；最后做深浅色、大字号、横屏、返回手势和实际学习流程验证。数据来源、编辑优先级等已有事实边界继续如实显示。
