# 数据一致性与验收清单

## 一次加入的定义

用户每次主动点击加入按钮生成唯一动作 ID。相同动作 ID 的重试只记一次；不同点击各记一次，创建多条待学习任务。累计加入次数通过事件记录聚合，不依赖一个容易失步的独立计数器。

完成一个学习任务只消费其任务 ID。更新任务、写入 FSRS 状态和写入答题记录在同一个 SQLite 事务中完成。复习提交同时检查当前记忆版本及到期时间，阻止过期界面重复计分。

重新加入不清除记忆历史。当一个词仍有未完成学习任务时，先出现在学习队列，避免同一时刻又在复习队列重复完成。

## 词典数据

词条来自完整基础 ECDICT CSV。转换过程校验 GitHub Git blob SHA-1、记录下载 SHA-256，并执行 SQLite integrity_check。词典单独建索引；启动时只把不可变词典复制进私有目录，不向内存加载全部词条。

自 0.4.0 起，义项统计使用独立 `exam-frequency.json` 证据目录，次数从已复核的逐次出现记录推导。旧 `exam_senses` 空表不再作为统计入口；一整行合并释义、单词频率或编辑顺序不能冒充义项统计。当前核验覆盖 0 词，缺失显示「未统计」。结构及审校要求见 [数据规范](考研义项频率数据规范.md)。

## 目标手机验收步骤

1. 安装 APK，确认启动成功、四个底部栏目可切换；“我的”显示离线词典条数。
2. 打开查词，搜索 address，检查读音、中文释义、全部释义、词形与英文释义；飞行模式下重复搜索。
3. 同一词连续加入三次，在词书确认一行显示累计三次、待学习三次。
4. 完成一次学习，确认待学习变成两次、累计次数仍为三次。
5. 学习过程中退出并强制停止应用，重新打开，确认完成记录和剩余任务不丢失。
6. 学完后按显示的到期时间进入复习，比较加入次数不同的词，确认次数多者靠前。
7. 复习页未揭晓时不显示中文答案，揭晓后可选择四档评分；快速双击不能重复评分。
8. 在复习中选择忘记，稍后验证重学安排；切换系统日期/时区不应使累计任务变化。
9. 测试系统返回手势取消/完成、键盘显示、较大字号、深色模式、竖屏与横屏。
10. 在系统已安装英语离线语音时测试发音；缺失语音应给出说明，不自动下载。
11. 新建第二本词书并加入同一个词，确认两本的次数独立；删除一本中的词不会改变另一本。
12. 使用“清除个人学习数据”，确认所有词书与历史被清除，词典仍可查询。
13. 正常卸载后重新安装，确认词书为空、设置恢复默认，共享存储没有应用新建目录。

以上为待执行的真机验收步骤，不代表已经在目标手机上通过。
