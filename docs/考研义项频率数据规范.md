## 发布数据与排序

`app/src/main/assets/exam-frequency.json` 是独立、可审阅的统计目录，当前 `corpora`、`words` 均为空。APK 打包验证检查目录与源码逐字节一致。该目录不写入个人学习数据库，升级不改变词书、加入计数或学习进度。

- 一个词只使用一个明确的语料范围。语料包含英语（一）卷别、每份试卷 ID、年份、原件链接、标注方法链接、再分发许可。
- 每个义项有独立 ID 和中文文本，不直接把 ECDICT 一整行合并释义当作一个义项。
- 每次出现有试卷 ID、题型/题号/词位置及复核者；程序从出现记录推导次数，不接受孤立的 `count` 或百分比。
- 同一词在同一试卷同一位置不能被两个义项重复计数；证据必须指向语料内试卷。英语（二）数据被拒绝。
- 义项 `occurrences: null` 是未统计，`[]` 是在所声明语料中复核后为零，后者必须有明确复核者。不把缺数据填成 0。
- 已统计义项按次数降序，相同次数保持目录顺序；已核验 0 次之后才是未统计。次数只代表该语料，不能外推为所有真题或未来考试概率。
- 有数据时，学习页/查词页显示次数、语料范围；查词页可展开逐次出处。未纳入统计的原词典内容仍在「全部释义」。无数据时保留词典原顺序并明确「未统计」。

**代码只能验证结构与一致性，不能自动证明某个 URL、许可声明或人的复核结论真实。** 正式数据进入目录前，仍须人工核对原件、完整收录范围、分词归并、义项划分与多义消歧，确认合法授权，并记录审校结果。测试使用 `example.org` 的虚构证据，明确只作为测试夹具，不进入 APK 目录。

## JSON 字段约定

根：`schemaVersion: 1`、`corpora: []`、`words: []`。

语料：`id`、`title`、`exam: "英语（一）"`、`papers: [{id, year, sourceUrl}]`、`methodologyUrl`、`license`。

词条：`word`（规范化英文）、`corpusId`、`reviewed: true`、`senses: [{id, text, reviewedBy, occurrences}]`。

出现记录：`paperId`、`location`、`reviewedBy`。`location` 必须能区分同一句中重复出现的词，不能只写年份。审校者必须确认已经穷尽声明范围内的该词出现位置，不能挑选几个例句后称为整体频率。

将来新增语料仍遵守先申请必要下载、数据存于项目目录、只考虑免费可信来源的约束。
