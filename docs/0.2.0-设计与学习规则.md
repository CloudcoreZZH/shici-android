# 0.2.0 设计与学习规则

本版适配重点为 Android 16。按用户的新决定，暂停澎湃 OS 专项设计与集成。

## 核心流程

查词 → 加入所选词书 → 分组主动回忆 → 揭晓释义 → 如实评分 → 按 FSRS 安排下一次。

学习和复习统一评分操作，避免“学习先选认识、再确认”和“复习直接评分”带来的认知切换。四档评分分别是忘记、困难、记得、轻松；后面三档都要求确实想起答案。按钮展示预计间隔，便于理解选择的结果。

复习安排页不再显示中文释义，避免刚看过答案就误判为已经记住。学习页仅在揭晓后显示释义和例句，次要信息可以展开阅读。

## 加入、学习与复习的关系

- 每次有效点击加入都会增加一条独立学习任务，累计次数不因学习完成而减少。
- 每组默认 10 词，可改为 5 或 20 词。同一词在一个新组中只选一条加入任务，其余加入任务保留给后续组。
- 学习选“忘记”会记录真实答题表现、更新记忆状态，但不完成该学习任务。任务按算法产生的间隔进入等待，继续处理本组其他可学词。
- 全部剩余词尚未到期时显示等待页；退出后仍可继续这一组。不会通过立即连续点相同词把未记住的任务消耗掉。
- 等待时若还有其他可学词，可以主动选择“先学其他词”另开一组。等待任务仍保留，不会被完成或删除；同词的后续加入任务也不能绕过前一条遗忘任务的等待时间。
- 学习选困难、记得或轻松表示已实际回忆成功，才完成一条加入任务。学习任务全部完成后，该词按记忆状态进入复习队列。
- 复习仅选择已到期、没有待学任务的词，累计加入次数降序优先，同次数再按到期时间排序。一次复习评分即记录一次复习；忘记会安排短时巩固，不等于已掌握。
- 暂停后重新加入的词会移出原复习组，先完成新学习任务，避免旧复习界面与新任务冲突。

## 恢复、撤销和升级

答题、记忆状态、任务完成情况、续学进度在同一数据库事务中保存。强制退出后，剩余组仍可恢复，答案会重新隐藏。

本组最近一次答题可撤销；撤销还原先前记忆状态、任务完成情况、等待时间及计数。被撤销记录保留审计标记，不计入当日复习统计。若该词已经发生后续答题，则拒绝撤销过期记录。

学习数据库从版本 1 升至版本 2，使用增加字段和表的迁移，不删除原词书、加入事件、记忆或答题记录。发布仍使用原签名，供覆盖安装。

## 释义的编辑优先级

经用户确认，用明确标注的编辑优先级替代缺少依据的“考研义项频率”展示。本版整理 120 个词条的重点义项及 120 条原创双语说明例句。资料在 `app/src/main/assets/editorial-notes.tsv`，全部随 APK 离线提供。

这些顺序是学习建议，并非对考研真题逐义项计数；例句不是历年真题，也不是商业词典引文。编辑版并非已经过专业词典机构审校的资料。完整 ECDICT 释义保留在“全部释义”中，未覆盖词条保持原释义顺序。不能把这 120 词的编辑覆盖说成整个离线词库都已做考研义项整理。

## 视觉与 Android 16

采用暖白底色、深绿强调色、统一圆角与文字层级。首页以当前任务和下一步操作为主；学习中让单词、释义和评分保持稳定的位置。去掉原来占据首页的大面积山景和固定“今日一词”，避免装饰压过任务信息。

评分按钮在较宽窗口排成一行，手机窄屏排成两行；内容支持滚动、系统字号、深色模式和安全区域。返回动画随左右手势边缘采用对应位移方向，键盘与系统栏使用窗口 Insets 处理。

参考：[Android 16 面向 API 36 的行为变化](https://developer.android.com/about/versions/16/behavior-changes-16)、[FSRS 官方算法](https://github.com/open-spaced-repetition/fsrs4anki/wiki/The-Algorithm)。这些实现不代表已完成所有品牌真机的性能与兼容性验证。
