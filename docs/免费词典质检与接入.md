2026-09-18，用户明确批准免费数据、署名和共享许可，下载上限 85 MB，解析缓存上限 300 MB。原始资料位于 `.downloads/open-dictionary/`，生成库位于 `app/src/main/assets/references.db`，不写入系统或 Python 环境。

## 来源与许可

- [中文维基词典的 Kaikki 抽取](https://kaikki.org/zhwiktionary/)：2026-09-01 dump，网页记载 2026-09-15 抽取。“英語”和“英语”是两个语言名称分区，不表示各分区纯繁体或纯简体。两个文件合并处理。中文维基词典贡献者保留著作权；使用 CC BY-SA 4.0，保留 Kaikki / Wiktextract 归属。
- [NETEMVocabulary](https://github.com/exam-data/NETEMVocabulary)：固定提交 `70dc6b68c855f21e666a7a291ff8ead5ca1f7b44`，数据 CC BY-NC-SA 4.0。2024 参考词表按其作者表述记录，不保证它已经通过官方校对；没有把它改称 2027 大纲。
- 许可全文在 APK 资源中，应用“我的”页面可离线阅读；原词条和来源链接通过用户主动点击在外部浏览器打开，应用自身仍没有联网权限。
- 两个来源在数据库中分别存于 `definitions` 与 `netem_2024`，各自派生数据继续采用原许可，未把 CC 数据改许可成 MIT。许可署名不涉及 Git 提交作者或贡献者账号。

## 处理方法

`scripts/prepare_references.py` 完全离线，先校验已下载文件的大小和 SHA-256，再生成只读库。只规范化搜索键、过滤、去重和翻译已识别的标签；保留原中文义项及其顺序，不自动生成释义或考研优先级。

过滤非英语、未知或不适用词性、不可检索的词头、空/无中文释义、纯词形/变体说明、损坏字符和未展开模板。短语词性却只有单词词头的条目可能丢失短语标题，过滤以免把搭配含义误认成单词含义。原词头大小写分别保留；例如 `Hospital` 人名与 `hospital` 医院不会合并成一个来源记录。

保留原文中的简繁体，不下载转换工具，也不未经审校改写。未知用法标签保留原标签。数据筛选只证明格式和可追溯性，不能证明所有语义正确。

NETEM 简略释义不能覆盖完整词性和义项；其单词频数混合多个考试，也不是逐义项次数。因此只保存 2024 词表成员与原变体字段，界面仅显示历史收录标记；不把简略释义提升为默认答案，不导入频数或排行。
