# 0.3.0：按天复习与动画

本版完成日历日调度、界面过渡改进和经批准的免费词典补充。原 ECDICT 上新增 33,998 词的维基参考释义（9,841 个新增词）；NETEM 仅用于 2024 词表对照。2027 年英语（一）完整大纲与全量义项优先级尚未核验，编辑排序仍为 120 词，不能把本版称为词典与考研排序全量完成。[质检说明](免费词典质检与接入.md) · [数据来源与授权调研](词典与完整大纲授权调研.md)

## 每天一次的复习节奏

- 使用 FSRS-6 的 21 个默认系数及实际答题记录更新稳定性和难度，取消固定的分钟级学习/重学步骤。
- 每档评分都由记忆状态计算整数天间隔，范围 1–36,500 天。默认 90% 目标保持率的新词四档预览为 1 / 1 / 2 / 8 天；已学词不固定套用这组天数。
- “一天”按手机本地日历计算，目标日期从零点开始可复习。例如周一 23:55 选择 1 天，周二即可复习，不要求再等足 24 小时。界面使用“明天/后天/日期”，不显示分钟或小时倒计时。
- 因此 1 天是最早次日，不是承诺至少间隔 24 小时。午夜附近作答也按相同规则处理。
- 学习时“忘记”保留这次加入任务，到对应日期继续；其他可学词仍能进入新组。同一个词的后续加入任务不能绕过遗忘等待。
- 复习中的遗忘仍如实记录，安排下一个日期；不把遗忘显示为掌握。到期队列仍按累计加入次数优先。
- 采用日历日处理夏令时的 23/25 小时变化。复习预览、调度和日期标签使用相同的日期口径。
- 取整和最早次日的约束可能使实际保持率偏离所选目标。“目标保持率”不是保证正确率；按天安排符合本项目使用习惯，但不能证明它对每个人都比短时巩固效率更高。
- 未实现用户历史上的 21 系数训练优化器，也未做用户长期学习效果对照；不宣传绝对最优算法。

数学来源：[FSRS 官方算法](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)。本版沿用公开公式，项目策略是关闭短时步骤并以本地日期安排；不是新的自创记忆公式。

## 从旧版升级

个人数据库从版本 1 或 2 迁移到 3，在数据库事务内完成：

- 保留词书、加入事件、计数、原答题时间、稳定性、难度、次数及答题历史。
- 原同日分钟级安排移至上次答题后的次日；跨日安排保留对应日期，并在该日零点到期。旧逾期记录不会一律改成“明天”。
- 未完成的遗忘任务、已保存的学习组同步到新的到期日期；新加入的即时任务仍即时可学。
- 旧版最近一次评分的撤销入口关闭，防止撤销时恢复旧分钟安排。历史记录保留。升级后的新评分仍可撤销。
- 使用原签名覆盖安装；尚未在用户真机执行覆盖升级或卸载清理。

## 动画与 120 Hz

- 页面进入 240 ms、退出 140 ms，使用统一缓动；进入/返回方向一致，底部栏目按切换方向过渡。
- 单词切换与揭晓答案分别过渡，评分区域保持位置，避免答案展开把操作推离屏幕。
- 进度条平滑推进；预测性返回跟手缩放/位移，取消手势用阻尼弹簧恢复，不瞬间跳回。
- 首页增加未来 7 天复习日历，位于任务入口下方；只统计已进入复习的词，逾期计入今天。预测会随后续学习和评分变化，不把未来待学任务算成已经到期的复习。
- 采用 Compose 系统帧时钟和图层属性；不使用固定 16 ms 定时循环，也不人为限制为 60 帧。定时动画遵循系统动画时长设置。
- Android 16 对实际 Compose View 使用 `requestedFrameRate = 120f`，离开组合时恢复原请求。按官方机制，View 重绘时才投票；未强制切换分辨率或锁住静态显示模式。
- 前台数据刷新从每 30 秒轮询改为进入前台及下一本地日期边界刷新；用户的学习/查词操作仍即时刷新相关状态。
- 支持高刷新率不等于已验证持续 120 fps。系统高刷开关、省电/温控、硬件能力和渲染耗时仍会影响结果。

依据：[Android 官方自适应刷新率说明](https://developer.android.com/develop/ui/views/animations/adaptive-refresh-rate)、[Compose 动画说明](https://developer.android.com/develop/ui/compose/animation/composables-modifiers)。
