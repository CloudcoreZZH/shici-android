# 开发与下载方案

## 当前已核实的环境

- 工作区：`D:\课件\My App`，所有工程文件、构建缓存、下载文件与 APK 均保存在这里。
- Python：`D:\anaconda3\envs\NLP\python.exe`，仅在确实需要时运行。
- 初期只读复用 PyCharm JBR 21 完成核心编译；实际 Android 打包发现其缺少 jlink。用户随后明确批准完整 OpenJDK 21 下载，现使用项目内 `.tooling/jdk-21`，未修改 PyCharm。
- PATH 和常见目录中未发现可用 Android SDK、Gradle 或 adb。

## 工程选择

- 原生 Kotlin + Jetpack Compose；目标 Android 16 / API 36。
- 纯 Kotlin 核心层负责学习任务、复习规则和 FSRS 调度；Android 数据层负责持久化；Compose 展示层通过 ViewModel 调用用例。
- 词典只读数据库与个人学习数据库分离，避免更新词典损坏学习记录。
- 重复加入采用独立事件/任务，一次点击对应一次待学习任务；事务保护计数与任务一致性。
- 首版离线运行，无广告、分析 SDK、后台保活、账号登录、通讯录或存储权限。
- 所有自动产生的数据只写应用内部目录；关闭自动云备份和设备迁移备份。用户主动导出的文件由用户选择位置，并明确属于独立备份。

## 待授权的下载范围

为生成真实 APK，需要 Google Android 命令行 SDK、Android 36 平台、Build Tools、Platform Tools、Gradle，以及 Kotlin / Android Gradle Plugin / AndroidX / 测试依赖。

- 来源限定 Google 官方、Gradle 官方、Maven Central、JetBrains/Kotlin 的官方发行渠道。
- 预计首次下载总量约 0.7–1.5 GB，解压和构建缓存可能占 3–5 GB；这是估算，超过 1.5 GB 下载预算前重新申请。
- 不下载 Android Studio、安卓模拟器系统镜像、NDK 或大模型。
- 工具放 `.tooling/`，下载归档放 `.downloads/`，缓存放 `.cache/`，最终 APK 放 `dist/`。
- 使用 SDK 需要接受 Google Android SDK 许可：https://developer.android.com/studio#command-line-tools-only 。
- 用户已明确批准这份清单、Android SDK 许可及补充的完整 OpenJDK 21（约 205 MB）。所有后续新增类别或超出预算的下载仍需重新申请。

## 待决定的词典数据范围

ECDICT 是可用于离线查词的开源英汉数据候选，但其通用词频、考试标签不等于“考研真题每个义项的出现频次”。

用户已选择并批准先接入基础 ECDICT（实际下载约 66 MB）。真实考研义项统计使用独立、带来源的扩充数据。缺少统计的词明确显示“暂无考研义项统计”，不能用词条频次冒充义项频次。

如用户要求第一份交付就必须具有经过核验的全面考研义项频率，则还需选定覆盖年份、英语一/二范围及可用语料/词典来源，不能把此项当作已完成。

## 验证要求

- 核心测试覆盖重复加入、并发/重复提交、任务完成、复习排序、FSRS 数值与时间边界。
- 数据库测试覆盖事务和数据恢复边界。
- 编译、Lint 和适当的 UI/集成验证通过后交付 APK。
- 原生动画、澎湃系统行为和卸载清理必须在目标手机上进一步验收。没有真机测试就不声称完美适配。
