# 拾词 0.2.0

## 安装与升级

从 [v0.2.0 发布页](https://github.com/CloudcoreZZH/shici-android/releases/tag/v0.2.0) 下载 `shici-0.2.0.apk`，传到手机打开安装。本地文件名为 `拾词-0.2.0.apk`，内容相同。

**已安装 0.1.0 时直接覆盖安装，不要先卸载。** 本版沿用相同包名和签名，数据库采用保留数据的升级迁移。正常卸载或清除应用数据仍会删除学习记录；当前没有学习记录导出功能。

本版聚焦 Android 16，最低安装版本仍为 Android 12。没有新增系统权限，没有联网、广告、后台保活或自动下载。

## 新的学习方式

1. 查词后点击加入。次数会立即显示在底部，不再弹出阻断查词的面板；每一次有效点击仍是一条独立任务。
2. 进入学习，每组默认最多 10 个词，可在“我的”改成 5 或 20。连续加入三次的同一个词，会分布在不同组，不会因为合并展示而丢掉任务。
3. 先自己回忆，再点“显示答案”。选忘记、困难、记得或轻松，按钮上会显示预计间隔。后三项表示确实想起，只是费力程度不同。
4. **忘记不会消耗待学任务。** 它会稍后再次出现，其他可学词先继续。需要等待时可以退出，或选择“先学其他词”；已经完成的记录都会保存。
5. 误点评分，用右上角撤销上一条。学习任务、记忆状态和当天计数会一起还原。
6. 一组结束后显示真实答题结果和下一次复习安排，可以继续下一组，也可以先到这里。

## 复习有什么变化

复习安排页只显示词和顺序，不提前显示中文答案。已到期的词中，累计加入次数越多越靠前；尚未到期的词不会因为次数高就提前混进来。已有待学任务的词先完成学习。

复习选忘记会记录一次未能回忆，并按 FSRS 安排巩固。“完成一组复习”表示处理完这一组，不表示所有单词已掌握。FSRS 使用默认参数，根据每次真实答题更新记忆状态；暂未训练个人参数模型。

## 释义与界面

- 新增 120 个词条的编辑优先释义、120 条原创双语例句。**不是考研真题义项频率，也不是真题例句。** 没有覆盖的词继续使用 ECDICT 原释义；所有已覆盖词也能查看完整原释义。
- 首页直接显示待学、到期复习和当日进度，使用暖白、深绿的统一主题。
- 学习页突出单词、释义和评分；横屏使用左右布局，支持较大字号与深色模式。

## 验证与实际边界

47 项自动化测试通过，发布检查没有错误，保留 5 项非阻断提示（旧系统忽略属性、依赖版本更新、空资源目录）。同目录 `验证报告.json` 记录最终测试、发布检查、签名和 16 KB 对齐结果。截图见 `docs/screenshots/v0.2.0/`，来自 Android 16 测试环境的真实渲染，部分页面使用测试学习记录。

覆盖安装与已有数据、返回手势、系统键盘、离线发音、实际流畅度、进程被系统结束后的恢复，以及卸载清理，仍需在实际手机上验收。测试环境通过不能替代所有品牌真机验证。
