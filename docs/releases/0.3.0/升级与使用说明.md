# 拾词 0.3.0

本版交付免费词典补充、按天复习、复习日历、过渡动画和 Android 16 高刷新率支持。2027 英语（一）完整大纲与全量考研义项排序仍未核验，未随本版完成。

- 可使用原签名覆盖安装 0.1.0 或 0.2.0。请保留本机学习数据，勿先卸载。
- 复习间隔改成整数天，到期当天零点起可复习。最早次日，不要求严格等足 24 小时。
- 新词四档默认预计 1/1/2/8 天，后续间隔按真实答题记录计算；忘记不会消耗待学任务。
- 旧版同日分钟安排迁移到次日，已逾期记录保留逾期状态。词书、次数、记忆和答题历史保留。仅关闭升级前最后一条答题的撤销入口，升级后新答题可正常撤销。
- 页面、揭晓和换词过渡更连贯；取消返回手势会平滑恢复，评分区位置稳定。
- Android 16 向系统申请 120 Hz 绘制，系统仍决定实际刷新率。无需额外权限，不常驻后台、不持续刷新静止页。
- 保留 ECDICT 768,739 词条，接入 33,998 个词的维基补充释义，其中 9,841 个新增词可查可学。总计可检索 778,580 词。补充释义可在“全部释义”展开，保留简繁原文、词性、来源和许可。
- NETEM 的 2024 参考词表规范化后 5,528 词全部被原词典覆盖；只显示历史词表标记，不使用其中的混合考试词频排序义项。编辑排序与原创例句仍为 120 个词，不代表完整大纲。
- 维基数据采用 CC BY-SA 4.0；NETEM 对照采用含非商业条件的 CC BY-NC-SA 4.0。署名和许可在“我的”页面可见。

详细规则见 [按天复习与动画](../../0.3.0-按天复习与动画.md)。免费资料的覆盖、过滤和边界见 [质检说明](../../免费词典质检与接入.md)。没有连接到用户手机；120 fps、覆盖升级和卸载的实际表现仍待真机验收。
