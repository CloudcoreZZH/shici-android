# 拾词 0.1.0 安装与验收说明

交付日期：2026-09-18。本地安装文件：`拾词-0.1.0.apk`，Release 下载名为 `shici-0.1.0.apk`；两者内容相同，30,567,150 字节（约 30.6 MB）。

## 安装

1. 从 [GitHub Release](https://github.com/CloudcoreZZH/shici-android/releases/tag/v0.1.0) 下载 `shici-0.1.0.apk`，传到小米 13 Pro，使用手机文件管理器打开。
2. 按系统提示允许当前文件管理器安装此 APK，完成后打开“拾词”。无需 root、USB 调试或电脑连接。
3. 首次启动会将随包词典准备到应用私有目录，稍等即可。查词和学习均可离线使用。

若系统阻止安装，保留其具体提示，以便按实际问题处理；不要关闭系统的全部安全保护。以后使用同一签名的版本可以覆盖升级，无需先卸载。

## 开始使用

- **查词**：搜索英文，查看中文释义、音标、词形和英文释义。收录 768,739 个有中文释义的词条，来源为 ECDICT。
- **重复加入**：同一个词每主动加入一次，就增加一次累计次数和一条学习任务。例如加入三次，完成一次学习后，累计次数仍是三次，待学习剩两次。
- **学习**：先回忆，再揭晓答案，完成后自动保存。退出后已经完成的记录保留，未完成的任务仍可继续学习。
- **复习**：采用 FSRS-6，根据答题更新记忆状态。只安排已到期的词，同一队列内累计加入次数多的排在前面。还有待学习任务的词先完成学习，再进入复习。
- **词书与设置**：支持新建、切换词书，查看累计次数；支持浅色、深色和跟随系统，调整目标保持率。
- **发音**：使用手机已经安装的离线英语语音。没有可用语音时会提示，应用不会自动下载语音。

此次交付已通过 25 项自动化测试：9 项调度算法测试、11 项数据一致性测试、4 项学习界面测试，以及 1 项使用实际词库的完整查词—重复加入—学习—词书流程测试。

## 已知边界与真机验收

- 按本次确认，暂缺经过核验的考研真题义项频率。界面明确提示缺少统计，释义保持词典原始顺序；ECDICT 的原始释义可能包含较旧或专业领域的用法。
- FSRS-6 使用默认系数并跟随答题更新每个词的记忆状态；当前没有训练个人模型系数的优化器。
- 已以 Android 16（API 36）为目标构建。预测性返回、系统字号、键盘、横竖屏、后台恢复、英语离线发音，以及澎湃 OS 3 上的实际动画表现仍须在你的手机上验收。未接入小米超级岛。
- 推荐先用少量词验证重复加入和学习记录，再开始长期使用。完整真机验收步骤见工程 `docs/数据与验收.md`。

## 数据与卸载

应用没有联网、共享存储、通知、通讯录、悬浮窗、无障碍和开机启动权限，没有广告、统计上报或后台保活服务。词典副本、学习数据和设置均在应用私有目录；已禁用云备份与设备迁移备份。

正常卸载由 Android 删除应用私有数据。卸载后重新安装应恢复空词书，这一行为仍需在目标手机上确认。用户自己传到手机的安装 APK 由用户保管，卸载应用不会删除它。

**首版没有学习记录导出功能，卸载或清除应用数据会丢失学习记录。** 应用内“清除个人学习数据”会删除个人词书和学习历史，保留可用词典。

## 源码与后续升级

完整源码、构建脚本和工具均保存在当前工程目录。后续可运行 `scripts/build.ps1 -Offline` 使用已有缓存重新构建，无需修改系统 PATH。

请妥善保留工程中的 `.signing/`，它用于后续覆盖升级；不要公开该目录中的私钥和密码。发布给手机只需要 APK，不需要发送开发工具或签名文件。
