使用既有签名直接覆盖安装 0.1.0 / 0.2.0 / 0.3.0，无需卸载。0.4.0 不改变个人数据库版本，词书、累计加入次数、任务、答题记录和设置继续保留。不要为升级先卸载应用，卸载会清除个人数据。

## 本次变化

- 墨白书页设计：暖白、墨黑、朱红，衬线词头、平面列表、细分隔线和低圆角；同时适配深色、横屏与系统大字体。
- 释义按需显示；显示答案不再改变底部评分区域高度。换词与页面切换改为短淡入淡出，预测性返回减少逐帧分配。
- Compose 原生 120 Hz 绘制投票和手动本地帧耗时记录。静止页不强刷，记录默认关闭，不上传。
- 义项统计仅接受带试卷范围、复核与逐次出处的记录；次数自动推导，未统计置后。编辑顺序不再替代真实频率。
- 词书可用英文或已有中文释义筛选，复习日期不再显示具体时分。

## 必须说明的缺口

**真实义项频率数据覆盖仍为 0 词。** 已完成排序、校验、来源展示及缺失状态，但没有把真实统计填充完成。已有 ECDICT、中文维基词典和 NETEM 2024 都不能提供所需的英语（一）逐义项统计，应用如实标「未统计」。2027 完整大纲和所有中文释义的专业审校也未完成。

**尚未在小米 13 Pro 上验证这次掉帧改善。** 屏幕显示 120 Hz 不代表应用稳定绘制 120 FPS。本次 ADB 未连接目标手机。

## 手机复测

进入「我的 → 流畅度记录 → 开始记录 60 秒」，返回之前卡顿页面重复操作。60 秒后返回「我的」查看并复制记录，可附上具体卡顿操作。报告提供 P95 帧耗时及超过系统帧预算的比例，不把屏幕 Hz 或统计回调遗漏当作实际 FPS / 掉帧数。切到后台自动停止，退出进程后不保留报告。
